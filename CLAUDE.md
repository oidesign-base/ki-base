# CLAUDE.md — правила роботи над проєктом KI-BASE

Панель обліку й керування товарами (партії неотриманих посилок → товари → оголошення на платформах → продажі).
Ці правила діють для всіх розмов проєкту. Зміни до правил — тільки за окремою домовленістю.

## 1. Жодних дій без прямого запиту

- Нічого не створювати, не змінювати й не видаляти в коді, базах даних, інтерфейсі, конфігурації чи файлах проєкту без прямого запиту Олексія.
- **Питання — це питання, а не дозвіл.** «Чи можемо…», «чи можна…», «як це виправити?», «що скажеш?» → пояснити варіанти й зупинитися, чекаючи явного «роби» / «виправ» / «створюй».
- Дозвіл на одну зміну не поширюється на наступні. Кожна правка потребує окремого підтвердження.
- Якщо під час дозволеної роботи виявляється потреба в додатковій зміні, якої не було в запиті — спочатку сказати про неї й дочекатися рішення.

## 2. Мови

| Що | Мова |
|---|---|
| Назви баз, таблиць, полів, індексів | англійська |
| Змінні, функції, класи, файли, маршрути | англійська |
| Коментарі в коді, commit-меседжі, технічна документація | англійська |
| Інтерфейс панелі (підписи, кнопки, повідомлення, помилки) | польська |
| Дані в панелі: категорії, довідники, назви й описи товарів | польська |
| Тексти оголошень для платформ | мова платформи: Vinted, OLX, Facebook — польська; Etsy — англійська |
| Спілкування в чаті, LOG.md, цей файл | українська |

Тексти інтерфейсу не «зашивати» в код вроздріб там, де їх багато — тримати передбачуваний спосіб заміни.

## 3. Дизайн — тільки з шаблону `@template`

- Тека `@template` у корені проєкту — еталон дизайну панелі (Admina, Bootstrap 5.3.3). Звідти беремо верстку, класи, компоненти, кольори, іконки, логіку взаємодії.
- Тека `@template` — **тільки для читання**: нічого в ній не змінювати.
- Якщо для задачі потрібен елемент, якого в шаблоні немає, або наявна реалізація не підходить — **одразу спитати**, як бути. Не вигадувати власні компоненти й не підключати сторонні бібліотеки без узгодження.

- Кожен день роботи над проєктом (або на окреме прохання) туди додається запис: рішення, зміни, ідеї, відкриті питання.
